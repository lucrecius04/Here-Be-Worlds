# Pro jazykové modely a autory

Here Be Worlds je český kurátorský atlas herních světů (Astro, GitHub Pages).

- **Psaní esejí ke stezkám a studium knih:** začni v `docs/pro-autory/README.md` (příručka pro autory) a `docs/pro-autory/studium-knih.md` (zadání ke studiu knih). Všechno potřebné k jedné stezce složí `npm run bundle:trail -- <id-stezky>` do `bundles/`.
- **Architektura webu, slovník a pravidla kódu:** `CLAUDE.md` (zdroj pravdy pro práci na webu).
- **Fakta o světech** jsou jen v kronikách `content/chronicles/*.md`. Odborné prameny jsou ve výtazích `docs/prameny/`.
