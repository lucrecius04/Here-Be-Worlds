# Prameny: studijní výtahy

Výtahy z odborných knih a textů, o které se opírají eseje a stezky atlasu (*Anatomie herního lore*, `content/trails/*.md`). Slouží k tomu, aby se knihy nemusely číst znovu: každý výtah má bibliografii, co přesně bylo čteno, klíčové pojmy s českými ekvivalenty, převyprávění s odkazem na kapitolu či stranu, **co z toho plyne pro Here Be Worlds** (světy, stezky, metoda) a kde už je pramen použitý.

Pravidla:
- Před psaním eseje nebo stezky projít tento rozcestník a příslušné výtahy.
- Výtahy jsou převyprávění. Doslovné citace jen krátké (do 15 slov) a výjimečně, protože repozitář je veřejný.
- Co výtah tvrdí o knize, musí vycházet z textu, který jsme četli. Nečtené části označit (oddíl „Dočíst“).
- Po použití pramene v textu doplnit oddíl „Kde už je použito“.
- Nová kniha = nový soubor `prijmeni-kratky-nazev.md` + řádek do tabulky níže.
